Meet N8N

"Your data. Your server. Your rules. No per-task fees. No artificial limits."

The best part? It's completely self-hostable. You run it on your own machine or server. Nobody else touches your data. And unlike Zapier, you don't pay per automation run.

Let's Build Something Stupid — But Practical

Here's my situation: I code late. Way too late. We're talking 2 AM, 3 AM, sometimes 4 AM. I don't have friends who are awake at those hours. So I automated one.

We're building a bot that checks the time every hour — and if it's past 10 PM and I'm still at my desk, it sends me AI-generated insults via Slack. Because nothing motivates sleep like a Slack notification roasting you at 2 in the morning.

Here's the full workflow, step by step:

01

Schedule Trigger — Set it to run every hour, all day, every day. This is the heartbeat of the workflow.

02

Code Node — A tiny function that checks if the current time is between 10 PM and 4 AM. If it is, it returns shouldRemind: true.

03

IF Node — If shouldRemind is true, continue. Otherwise, do nothing. Workflow stays quiet during daylight hours.

04

OpenAI Node — Pass in a prompt that says: roast me harder depending on how late it is. 11 PM gets a gentle nudge. 3 AM gets destroyed.

05

Slack Node — Send the AI's roast to a dedicated Slack channel. Watch the message appear in real time. Feel shame. Go to sleep.

Five nodes. Maybe 10 minutes of setup after you grab your ChatGPT API key and create a Slack bot. And now you have a workflow that runs completely autonomously, every single hour — judging you so your friends don't have to.
